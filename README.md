# 🎬 Cinema Ticket Booking System

A web-based **Cinema Ticket Booking System** developed using PHP and MySQL that allows users to browse movies, check show timings, book tickets online, and manage reservations efficiently. The system also includes an admin panel for managing movies, shows, schedules, and bookings.

---

# 🚀 Features

## 👤 User Module

* User Registration & Login
* Browse Available Movies
* View Show Timings
* Online Ticket Booking
* Seat Selection
* Booking Confirmation
* Ticket Cancellation

## 🎥 Movie Management

* Add New Movies
* Update Movie Details
* Delete Movies
* Manage Movie Posters & Information

## ⏰ Show Management

* Add Show Timings
* Update Show Schedules
* Delete Shows
* Manage Available Seats

## 🛠️ Admin Panel

* Manage Users
* Manage Movies & Shows
* View Bookings
* Track Ticket Sales
* System Administration

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/Cinema-Ticket-Booking-System.git
cd Cinema-Ticket-Booking-System
```

---

## 2️⃣ Setup Database

1. Open **phpMyAdmin**
2. Create a new database:

```sql
cinema_booking
```

3. Import the provided SQL file into the database

---

## 3️⃣ Configure XAMPP/WAMP

* Move project folder to:

```bash
htdocs/
```

* Start:

  * Apache
  * MySQL

---

## 4️⃣ Run the Project

Open browser:

```bash
http://localhost/MOVIE_TICKET_BOOKING
```
